# Безопасность проекта

Безопасная разработка в приоритете. Перед пушем проверь изменения, историю новых коммитов и контекст сборки на секреты и персональные данные. Реальные ключи, токены, пароли, cookie, базы с данными игроков и сведения о частной инфраструктуре храни вне Git. Для тестов используй синтетические данные. В сообщениях и журналах показывай только результат проверки.

Развёртывание предназначено для выделенного игрового VPS. Обновления сервер забирает сам. Ключи администрирования остаются у владельца. Доступ приложения и CI к другим серверам владельца запрещён.
